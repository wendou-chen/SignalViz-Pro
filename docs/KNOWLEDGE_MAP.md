# SignalViz-Pro 知识地图

## 使用方式

这份知识地图服务两个目标：

- 帮你在复试前用“知识域 → 题型 → 模块”的方式组织复习
- 帮你在新增内容时先判断是否值得升级为独立可视化模块

## 一、基础理论

| 考点 | 典型题型 | 对应模块 | 推荐先修 |
|---|---|---|---|
| 时移、反折、尺度变换 | 根据图像写表达式、已知变换求波形 | 信号基本运算 | 连续时间信号 |

| 时域与频域对应 | 常见信号 CTFT、带宽理解、窗效应 | 连续时间傅里叶变换 | 积分、复指数 |
| 采样与重建 | 奈奎斯特判据、混叠判断、表观频率 | 采样定理与混叠效应 | 正弦信号、频率概念 |
| 卷积几何意义 | 翻转滑动、面积法、系统响应直观理解 | 卷积演示 — 翻转滑动法 | LTI 基础、积分 |

## 新主题该怎么放进系统

### 应扩展现有模块

满足以下任一情况即可优先扩展原模块：

- 只是同一公式下的参数变化
- 只是同一知识点的另一种观察角度
- 只是为了补一类边界案例或典型误区

### 应新增独立模块

只有同时满足以下条件时，才考虑新增页面：

- 能覆盖至少 3 类题型
- 有清晰核心公式
- 至少 2 个有效交互参数
- 至少 1 个值得可视化的现象
- 不能被现有页面自然吸收

### 只记入题库 / 笔记

如果只是：

- 单道题的技巧
- 某个非常窄的特殊结论
- 没有明显交互价值的推导过程

则不新建页面，只在后续题型笔记或蓝图文档中保留。
