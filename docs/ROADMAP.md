# SignalViz-Pro 复试前路线图

## 目标

在复试前，把项目从“内容可看”升级到“结构完整、叙事清楚、可持续扩展”。

## 已完成基础层

- 统一模块注册表
- 平台总览页与知识地图入口
- README 重写为 12 模块作品集主页
- 扩展准入规则文档化
- 轻量验证脚本与最小测试

## 阶段一：平台稳定化（当前版本完成后）

### 目标

让现有 12 个模块在展示和维护上足够稳。

### 完成标准

- 页面标题、导航、文档完全一致
- 所有核心页面侧边栏信息完整
- 验证命令可重复执行
- 推送前仓库状态干净

## 阶段二：高复用模块优先

### 第一优先级

1. **ROC / 因果 / 稳定性统一视图**
   - 价值：能打通拉普拉斯、Z 变换、系统判定三条线
   - 完成标准：同时支持连续与离散两个视角，解释 ROC 与因果 / 稳定关系

2. **微分方程 → 零输入 / 零状态响应**
   - 价值：是复试非常常见的系统分析题型
   - 完成标准：展示输入、齐次解、特解与总响应之间的关系

3. **相关与匹配滤波**
   - 价值：能把信号与系统和通信检测连接起来
   - 完成标准：支持滑动相关、峰值检测与噪声下对比

### 第二优先级

4. **采样 - 重建 - 量化链路**
5. **滤波器与带宽 / 截止频率**
6. **AM / FM / PM 调制对比**

## 阶段三：从模块集合到教育系统

### 目标

把平台做成“能指导复习”的系统，而不是只展示图表。

### 可选增强

- 题型索引页
- 模块间跳转推荐
- 每个模块补“易错点 / 高频问法 / 口述要点”
- 面向复试口述的讲解提纲

## 每次新增内容前的检查清单

新增前先问四个问题：

1. 这个主题覆盖几类题型？
2. 它更适合扩展旧模块还是新增独立模块？
3. 它的交互参数是否足够清晰？
4. 它能否形成一个可观察的关键现象？

只要这四个问题里有两个答不上来，就先不要立刻开新页面。
